# Functional coverage

This is a clean-room feature map for common Plottr-style desktop workflows. Cloud sync, real-time collaboration, and web/mobile access are intentionally excluded by requirement.

| Workflow | ArcTrellis implementation |
|---|---|
| Visual timeline | Book-specific matrix of ordered chapters and colored plotlines |
| Scene cards | Drag/drop, detailed editor, status, POV, setting, word count, tags, notes, custom fields |
| Outlining | Books, chapters/beats, sections/acts, summaries, ordering |
| Series planning | Multiple books in one project, dashboard, side-by-side Series View |
| Characters | Searchable entries with categories, tags, long notes, image paths, custom sheets |
| Places / worldbuilding | Searchable entries with categories, tags, long notes, image paths, custom sheets |
| Notes | Categorized research, continuity, editing, and worldbuilding notes |
| Connections / family data | Typed relationships between character, place, and note entries |
| Templates | Five bundled templates plus save-current-project as reusable template |
| Editing companion | Per-scene editing notes and Planned/Drafted/Revised/Final/Cut workflow |
| Progress | Series goals, current counts, chapter/scene counts, drafted-scene counts |
| Find/filter | Full-series text search across outline, cards, bible, tags, and fields |
| Import | Structured Markdown hierarchy |
| Export | Word `.docx`, Markdown, timeline CSV, Scrivener project folder, print/PDF through Windows |
| Local resilience | Atomic writes, 20 rotating backups, timed recovery autosave |
| Personalization | Plotline names/colors, free-form sections/categories, custom fields, light/dark theme |
| Desktop integration | Self-contained x64 publish, file association, Start menu/desktop shortcuts, uninstaller |
