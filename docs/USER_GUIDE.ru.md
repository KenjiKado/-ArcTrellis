# Руководство пользователя ArcTrellis

## Первый запуск

ArcTrellis открывает галерею шаблонов. Выберите **«Стеклянный горизонт»**, чтобы изучить заполненный пример, структурный шаблон для работы с подсказками или **«Пустой проект»**. Сохраните проект в любом месте как файл `.arctrellis`.

## Язык интерфейса

На Windows с русским языком интерфейс автоматически открывается на русском. Язык можно в любое время изменить через меню **Язык → English / Русский**. Выбор сохраняется локально. Текст, введённый пользователем, и содержимое существующих проектов при переключении языка не изменяются.

## Обзор

Укажите название серии, автора, жанр, замысел, текущее количество слов и цель. Проект может содержать любое количество книг. На странице обзора отображается число книг, глав, карточек сцен, сюжетных линий, персонажей, мест и сцен в работе.

## Хронология

Выберите книгу в верхней части окна. Столбцы соответствуют главам или структурным событиям, строки — сюжетным линиям. Дважды щёлкните пустую ячейку, чтобы добавить в неё сцену. Перетащите карточку сцены в другую ячейку, чтобы изменить её главу и сюжетную линию. Дважды щёлкните карточку, чтобы открыть подробный редактор.

С помощью полей рядом с выбором сюжетной линии можно изменить её название и цвет. Цвет задаётся в шестнадцатеричном формате, например `#5B7CFA`. Кнопки масштаба изменяют ширину карточек. Команда **Файл → Печать хронологии** отправляет текущую хронологию на принтер Windows или виртуальный PDF-принтер.

## План и сцены

Вкладка **План** управляет порядком глав, названиями актов и разделов, краткими описаниями и количеством слов. При удалении главы после подтверждения удаляются и её сцены.

Вкладка **Сцены** хранит название, рабочий статус, точку зрения, место действия, количество слов, теги, краткое описание, текст или рабочие заметки, редакторские заметки и произвольные дополнительные поля. Теги вводятся через запятую.

## Энциклопедия истории

Персонажи, места и заметки содержат имя, категорию, теги, краткое и полное описание, необязательный путь к изображению и произвольные поля. С их помощью можно создать любую анкету: цели и конфликты персонажа, правила магии, климат места, состояние улики или источник исследования.

Вкладка **Связи** соединяет любые две записи энциклопедии. Она подходит для родственных связей, союзов, соперничества, владения, путешествий и любых других отношений.

## Серия и поиск

Вкладка **Серия** размещает основы всех книг рядом, чтобы упростить работу с общей структурой и непрерывностью. Поиск охватывает книги, главы, сцены, черновые и редакторские заметки, персонажей, места, теги и дополнительные поля. Дважды щёлкните результат, чтобы открыть его редактор.

## Шаблоны

Встроенные шаблоны — это редактируемые примеры. Любой элемент можно переименовать, переместить, добавить или удалить. Команда **Файл → Сохранить как шаблон** сохраняет текущий проект как новый шаблон. Для каждого нового проекта внутренние идентификаторы создаются заново.

## Сохранение и восстановление

Нажмите `Ctrl+S`, чтобы сохранить проект. Перед перезаписью ArcTrellis копирует предыдущую версию в папку `ArcTrellis Backups` рядом с проектом и хранит 20 последних копий. Пока есть несохранённые изменения, отдельная копия для восстановления создаётся каждые 45 секунд. Если при открытии найдена более новая автокопия, программа предлагает восстановить её.

ArcTrellis не отправляет проекты в сеть. Файл проекта представляет собой обычный JSON в кодировке UTF-8.

## Импорт и экспорт

Импорт Markdown распознаёт структуру:

```text
# Проект
## Книга
### Глава
#### Сцена
После заголовка сцены следует её текст.
```

Доступные форматы экспорта:

- **Word (.docx)** — стандартный документ Open XML.
- **Markdown** — переносимый текстовый план.
- **CSV** — одна сцена в строке для анализа в электронной таблице.
- **Проект Scrivener** — папка `.scriv` с иерархией и RTF-документами сцен.
- **Печать / PDF** — через стандартную систему печати Windows.

## Сочетания клавиш

- `Ctrl+N` — новый проект из шаблона
- `Ctrl+O` — открыть проект
- `Ctrl+S` — сохранить
- `Ctrl+Shift+S` — сохранить как
- `Ctrl+Z` / `Ctrl+Y` — отменить / повторить структурное изменение

## Локальные папки

- Автовосстановление: `%LOCALAPPDATA%\ArcTrellis\Autosave`
- Пользовательские шаблоны: `%LOCALAPPDATA%\ArcTrellis\Templates`
- Резервные копии: папка `ArcTrellis Backups` рядом с сохранённым проектом
